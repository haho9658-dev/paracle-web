# tools

## render_mechanism.py

솔루션 섹션의 **캐스터 락 작동 원리 도식**을 생성해 `index.html` 과 `css/style.css` 에 반영합니다.

도식은 손으로 그린 것이 아니라 3D 좌표를 투영해 계산한 것이라, 시점을 바꾸면 화면 좌표가
전부 달라집니다. 그래서 SVG 를 직접 수정하지 말고 이 스크립트를 다시 돌리세요.

```bash
python tools/render_mechanism.py             # 현재 각도(55, 24)로 다시 생성
python tools/render_mechanism.py 55 24       # 방위각 55도, 앙각 24도
python tools/render_mechanism.py 60 26 --dry-run   # 파일은 그대로 두고 값만 확인
```

실행 후에는 **`index.html` 의 `?v=` 캐시 버전을 올려야** 방문자가 새 파일을 받습니다.

```html
<link rel="stylesheet" href="css/style.css?v=7">   <!-- 8 로 -->
<script src="js/main.js?v=7"></script>             <!-- 8 로 -->
```

### 각도 고르기

| 인자 | 뜻 | 권장 |
|---|---|---|
| 방위각 (alpha) | 좌우로 도는 각. 0이면 정면, 90이면 완전 측면. 키울수록 휠체어 오른쪽이 많이 보인다 | 30 ~ 60 |
| 앙각 (beta) | 위에서 내려다보는 각. 0이면 눈높이 | 20 ~ 28 |

**앙각을 35도 이상 주지 마세요.** 정 아이소메트릭에 가까워지면서 뒷바퀴 두 개가 겹치고
좌석이 덩어리로 뭉쳐 휠체어로 읽히지 않습니다. 실제로 겪고 되돌린 문제입니다.

### 요 회전을 3D로 만드는 원리

바퀴는 원판이고 굴림 방향은 `d = (sinθ, cosθ, 0)` 입니다. 투영이 선형이므로 원판의
정사영은 두 켤레 반지름

```
A = P(d) = r·( sin(θ+α),  −sinβ·cos(θ+α) )
B = P(z) = r·( 0, −cosβ )
```

으로 정의되는 타원이 됩니다. 따라서 단위원에 `matrix(Ax, Ay, Bx, By, Cx, Cy)` 를 걸면
요 회전이 근사가 아니라 **정확하게** 재현됩니다. 스크립트가 요각별 행렬을 뽑아
`@keyframes isoCasterA / isoCasterB` 로 내보냅니다.

### 함께 다시 계산되는 것

시점 하나만 바꿔도 아래가 전부 따라 바뀌므로 스크립트가 한 번에 처리합니다.

- 장면 기하 (승강장 · 점자블록 · 틈 · 전동차 · 휠체어)
- 캐스터 요 회전 keyframe 행렬, 잠금 상태의 고정 행렬
- 전동차 진입 이동량 (`@keyframes isoEnter`)
- viewBox 에 맞춘 스케일과 오프셋

### 안전장치

`style.css` 에서 고쳐야 할 규칙(keyframes, `iso-caster-a/b` 잠금 행렬, `isoEnter` 종료
키프레임)을 하나라도 못 찾으면 **아무것도 쓰지 않고 메시지와 함께 중단**합니다.
CSS 를 리팩터링해 선택자 형태가 바뀌면 스크립트의 정규식도 함께 고쳐야 합니다.

### 도식의 그리기 순서

정면이 아니라 비스듬한 시점이라 겹침이 생깁니다. 깊이 순서대로 그려야 정리됩니다.

```
먼 쪽 뒷바퀴 → 차체(등받이·좌석·프레임) → 가까운 쪽 뒷바퀴 → 보조 바퀴·앞 캐스터
```

좌석과 등받이는 불투명 면이라 뒤쪽 요소를 가립니다. 이걸 반투명으로 바꾸면
뒷바퀴가 비쳐 보이면서 형태가 뭉개집니다.
