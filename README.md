# Paracle Mobility — 기업 소개 웹사이트

수동 휠체어용 **캐스터 락 보조 바퀴 모듈**을 개발하는 파라클 모빌리티의 기업 소개 사이트입니다.
순수 HTML / CSS / JavaScript로만 구성되어 있으며 빌드 도구나 프레임워크가 필요 없습니다.

내용은 사내 사업계획서를 근거로 작성했으며, 인용된 통계는 국토교통부·한국소비자원·보건복지부 등
공개 자료를 출처로 합니다.

## 실행 방법

`index.html`을 브라우저에서 바로 열어도 동작합니다. 로컬 서버로 띄우려면:

```bash
python -m http.server 5173
```

이후 브라우저에서 `http://localhost:5173` 으로 접속합니다.

## 배포 (GitHub Pages)

`main` 브랜치에 push하면 자동 배포됩니다. 별도의 빌드 단계는 없습니다.

```bash
git add -A
git commit -m "수정 내용"
git push
```

1~2분 뒤 반영되며, 진행 상황은 저장소의 **Actions** 탭에서 확인할 수 있습니다.

### 설정 기록

- Pages 소스: **Deploy from a branch** → `main` / `/ (root)`
- `.nojekyll` — Jekyll 처리를 건너뛰어 빌드를 단순화하고 `_`로 시작하는 파일도 그대로 서빙
- `CNAME` — 연결된 커스텀 도메인 (`www.paracle.kr`). **이 파일을 지우면 도메인 연결이 끊깁니다.**
  GitHub 설정 화면에서 도메인을 바꾸면 이 파일도 자동으로 갱신됩니다.
- `.gitignore` — 사업계획서(PDF/HWP), 내부 문서가 공개 저장소에 올라가지 않도록 차단.
  새 문서를 추가했을 때 `git status`에 뜨지 않는다면 의도대로 막힌 것입니다.

### 도메인 DNS 설정 (등록기관에서 1회 설정)

| 타입 | 호스트 | 값 |
|---|---|---|
| CNAME | `www` | `haho9658-dev.github.io` |
| A | `@` (루트) | `185.199.108.153` / `185.199.109.153` / `185.199.110.153` / `185.199.111.153` |
| AAAA | `@` (루트) | `2606:50c0:8000::153` / `2606:50c0:8001::153` / `2606:50c0:8002::153` / `2606:50c0:8003::153` |

대표 주소는 `www.paracle.kr`이며, 루트(`paracle.kr`)로 들어와도 자동으로 `www`로 넘어갑니다.
등록기관의 **웹 포워딩(URL 포워딩) 기능은 쓰지 마세요** — HTTPS 인증서가 발급되지 않습니다.
반드시 위 DNS 레코드로 설정합니다.

## 주요 기능 (`js/main.js`)

- **캐스터 락 인터랙티브 도식** — 버튼으로 `FREE`(요 축 자유 회전) ↔ `LOCKED`(요 축 고정) 상태를
  전환하며 SVG가 애니메이션됩니다. 지하철 승강장에서 전동차로 들어가는 장면을 오른쪽 대각선
  위(3D 축측투영)에서 보여주며, 캐스터 바퀴의 요 회전을 `matrix()`로 실제 3D처럼 재현합니다.
  자세한 원리와 시점 조정 방법은 `tools/README.md` 참고
- **차트** — 문제 인식 섹션의 지역별 저상버스 보급률(17개 시·도 전체 막대 리스트) · 사고 통계
  미니 차트, 시장·BM 섹션의 시장 성장 곡선. 전부 손으로 그린 HTML/CSS/SVG 컴포넌트이며
  라이브러리를 쓰지 않습니다. `.chart-panel`·`.bar-chart`·`.bar-row`가 핵심 컴포넌트
- 스크롤 진행률 바 · 헤더 상태 전환 · 현재 섹션 네비게이션 하이라이트
- `IntersectionObserver` 기반 스크롤 등장 애니메이션 — 차트의 막대 채움·곡선 그리기 애니메이션도
  새 코드 없이 이 관찰자가 붙이는 `.is-visible` 클래스 하나로 동작합니다
- 숫자 카운트업 애니메이션 (35.5% / 41.2% / 304억 달러 등)
- 모바일 햄버거 네비게이션 (ESC · 링크 클릭 · 리사이즈 시 자동 닫힘)
- 문의 폼 검증 + Formspree 전송 (전송 중 버튼 잠금, 실패 시 사유 표시)

> **id를 지우면 스크립트가 조용히 멈추지 않고 크게 죽습니다.** `main.js`는 하나의 IIFE라
> `getElementById('...')`가 `null`을 반환하는 순간 그 뒤에 있는 코드(문의 폼 검증·제출 처리
> 포함)가 전부 실행되지 않습니다. 실제로 도식을 다시 그리며 `id="mechLeverLabel"` 텍스트가
> 통째로 빠졌던 적이 있는데, 콘솔의 `console.error`만 보고는 못 잡았습니다(uncaught exception은
> `pageerror` 이벤트로 잡아야 보입니다) — 폼이 검증 없이 그대로 Formspree로 나가는 것을 보고서야
> 발견했습니다. SVG·HTML을 고칠 때는 `main.js`가 참조하는 id 목록과 대조하세요:
> `mechSvg` `mechLever` `mechLeverLabel` `mechBtn` `mechBtnLabel` `mechState` `mechText`
> `contactForm` `formStatus` `formSubmit` `nav` `navToggle` `siteHeader` `scrollProgress`
> `toTop` `year`.

## 문의 폼 (Formspree)

폼은 [Formspree](https://formspree.io)로 전송됩니다. 백엔드 없이 동작하며 무료 플랜은 월 50건입니다.

엔드포인트: `https://formspree.io/f/xwlkwazq` (`index.html`의 form action)
받는 이메일 주소는 코드가 아니라 **Formspree 대시보드**에서 변경합니다.

> **배포 후 최초 1회** — 첫 문의가 들어오면 Formspree가 확인 메일을 보냅니다.
> 그 링크를 눌러야 이후 문의가 메일로 전달됩니다. 누르기 전까지는 메일이 오지 않습니다.

엔드포인트를 미설정 상태(`YOUR_FORM_ID`)로 되돌리면 전송을 시도하지 않고
"문의 접수 기능을 준비 중입니다"라고 안내합니다. 접수되지 않았는데 접수됐다고 표시하는 일은 없습니다.

### 구현 참고

- **동의 체크박스** — 개인정보보호법상 수집·이용 동의가 필요해 필수 항목으로 두었습니다.
  보관 기간(현재 "1년")은 실제 운영 방침에 맞게 `index.html`에서 수정하세요.
- **허니팟** — `_gotcha` 숨김 필드. 봇이 값을 채우면 Formspree가 자동으로 걸러냅니다.
- **전송 실패 시** 입력 내용을 지우지 않습니다. 성공했을 때만 폼을 비웁니다.
- 무료 한도(월 50건)를 넘으면 다음 달까지 접수가 막히므로, 문의가 늘면 플랜을 확인하세요.
- Formspree는 미국 서비스입니다. 개인정보 국외 이전 고지가 필요한지 확인이 필요하면
  받는 주소를 국내 메일로 두고 처리방침에 명시하는 방식을 검토하세요.

## 반응형 · 모바일

브레이크포인트는 **1024 / 860 / 520 / 400px** 이며, 320px(iPhone SE)까지 가로 스크롤 없이 동작합니다.

- **레이아웃** — 카드 그리드는 `repeat(auto-fit, minmax(250px, 1fr))`로 태블릿 2열 → 폰 1열로 접힙니다.
  제목의 `<br>` 강제 줄바꿈은 860px 이하에서 해제되어 자연스럽게 흐릅니다.
- **비교표** — 좁은 화면에서 가로 스크롤됩니다. 잘려 있다는 것을 알 수 있도록
  "좌우로 밀어서 전체 보기" 힌트와 오른쪽 페이드를 표시하고, 끝까지 밀면 사라집니다.
  스크롤이 필요 없는 넓은 화면에서는 둘 다 나타나지 않습니다.
- **캐스터 락 도식** — SVG는 통째로 축소되므로 520px / 380px 이하에서 라벨 단위를 키워
  실제 표시 크기를 11~13px로 유지합니다. 태블릿 이상에서는 도식과 함께 자연스럽게 커집니다.
- **터치 대응** — `@media (pointer: coarse)`로 화면 폭과 무관하게 탭 영역 44px를 확보하고
  (가로 모드 태블릿처럼 넓지만 터치인 경우 포함), hover 이동 효과를 끕니다.
- **모바일 메뉴** — 열려 있는 동안 뒤 본문 스크롤을 잠급니다. 링크 클릭 · ESC · 화면 확대 시 닫힙니다.
- **입력란** — iOS Safari가 포커스 시 화면을 확대하지 않도록 860px 이하에서 `font-size: 16px`.

## 접근성 · 호환성

- 시맨틱 마크업, `aria-*` 속성, 본문 바로가기 링크, 키보드 포커스 링
- 가로 스크롤 표는 `tabindex="0"`으로 키보드에서도 스크롤 가능
- `prefers-reduced-motion` 대응 — 모션 최소화 설정 시 애니메이션 비활성화
- 인쇄 스타일 포함 (헤더·폼 등 비출력 요소 숨김)
